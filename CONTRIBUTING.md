# Contributing

Bug reports and pull requests are welcome.

- **Bugs:** open an issue with your MATLAB version, toolboxes, the settings JSON, and the error message. A small cropped TIFF that reproduces the problem helps most (do not upload unpublished data).
- **Code:** keep each step in its own `modules/vt_*.m` function, add new parameters to `vt_defaults.m`, and run `runtests('tests')` before opening a pull request.
